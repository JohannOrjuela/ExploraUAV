# 🚀 ExploraUAV

Sitio web corporativo de **ExploraUAV**, enfocado en la presentación de servicios geoespaciales con drones: **LiDAR, fotogrametría, cartografía, catastro y capacitación**.

---

## 📌 Descripción

Este proyecto corresponde al frontend web de ExploraUAV, construido con React y Vite. La plataforma comunica la propuesta de valor de la empresa, sus servicios, proyectos y canales de contacto.

## ✨ Características principales

- Navegación multi-página con rutas internas.
- Secciones corporativas: Inicio, Nosotros, Servicios, Proyectos y Contacto.
- Páginas específicas por servicio:
  - LiDAR
  - Fotogrametría
  - Cartografía
  - Capacitación
  - Catastro
- Diseño visual orientado a marca con recursos multimedia (imágenes y video).
- Botones de contacto directo por WhatsApp y correo.

## 🧰 Tecnologías utilizadas

- **React 19**
- **Vite 7**
- **React Router DOM 7**
- **ESLint 9**
- **CSS** (estilos personalizados)

## ⚙️ Instalación y ejecución local

> Requisitos previos: **Node.js 20+** y **npm**.

1. Entrar al frontend:

```bash
cd frontend
```

2. Instalar dependencias:

```bash
npm install
```

3. Iniciar entorno de desarrollo:

```bash
npm run dev
```

4. Abrir en navegador (por defecto):

```text
http://localhost:5173
```

## 🧪 Scripts disponibles

Desde la carpeta `frontend/`:

- `npm run dev` → servidor de desarrollo
- `npm run build` → build de producción
- `npm run preview` → previsualización del build
- `npm run lint` → análisis de calidad con ESLint
